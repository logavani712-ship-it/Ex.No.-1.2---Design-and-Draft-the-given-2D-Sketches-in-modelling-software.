 ## PROCEDURE:

  1. Open Autodesk Fusion 360 software and create a new design. Select the Create Sketch option from the toolbar and choose the required sketch plane.
  2. Select the Circle tool and draw the main circles according to the given engineering drawing. Use the Sketch Dimension tool to specify the required diameters.  

 ![image](https://user-images.githubusercontent.com/113594316/198232594-2187c1c1-4e85-437f-99f7-263bb1a3e968.png)
 3 .Draw the remaining circles at their respective positions. Make sure that the circles are aligned properly according to the dimensions given in the reference     drawing.  
 
 4. Select the Line and Arc tools to draw the connecting lines and curved portions. Join the required features to form the outer profile of the component.
 5. Apply the required geometric constraints to maintain proper alignment and connections between the sketch elements. Ensure that the lines and curves meet correctly without unwanted gaps 
 6.  Apply the necessary dimensions to the lines, circles and arcs using the Sketch Dimension option. Check the measurements carefully to maintain the correct shape and size.

 9.After completing the sketch, select Inspect and click Measure. Check the distances and dimensions of the required features to verify their accuracy.

 ![image](https://user-images.githubusercontent.com/113594316/198232845-1608e574-732c-44b2-9921-39e920b70e2e.png)
 
 10.Inspect the entire sketch and compare it with the given reference drawing. Make the necessary corrections if any dimensions or positions are incorrect.
 
 11.Once the sketch is completed, click Finish Sketch to exit the sketching environment. Save the design using the required file name.

 ![image](https://user-images.githubusercontent.com/113594316/198232907-8275f39c-9031-4cf4-b0c4-8eb568e477ab.png)

 12.To prepare the engineering drawing, select Design, then Drawing, and choose From Design. Select the required drawing standard and sheet settings.   
 
 13.Choose the ISO standard, millimetre units and the required sheet size in the drawing settings. Click OK to create the drawing sheet.
 
 14.Arrange the drawing properly on the sheet and check whether the sketch is displayed clearly. Verify the final drawing before saving the completed design.
 
 15.Finally, save the completed Fusion 360 design and drawing for submission.
